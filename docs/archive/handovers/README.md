# Lưu trữ tài liệu handover

Các file trong thư mục này là snapshot bàn giao theo từng phiên phát triển. Chúng có thể chứa đường dẫn máy cục bộ, trạng thái vận hành và mô tả tính năng đã cũ.

Không dùng nội dung trong các snapshot làm trạng thái hiện tại. Hãy kiểm tra mã nguồn, GitHub Actions và cấu hình thực tế; dùng `README.md` ở thư mục gốc cho hướng dẫn đang áp dụng.
