✏️ Sửa Kênh YouTube #
📘 Hướng dẫn lấy refresh_token (Google Cloud + OAuth Playground)
  1. Tạo project tại Google Cloud Console → bật YouTube Data API v3.
  2. Cấu hình OAuth consent screen (External, thêm tài khoản Google của bạn vào Test users).
  3. Tạo OAuth Client ID loại Desktop app → lấy client_id và client_secret.
  4. Mở OAuth 2.0 Playground → ⚙️ → tick Use your own OAuth credentials → dán client_id/secret.
  5. Scope: https://www.googleapis.com/auth/youtube.upload và https://www.googleapis.com/auth/youtube.readonly → Authorize.
  6. Bấm Exchange authorization code for tokens → copy refresh_token.
  7. Dán JSON {"client_id":"...","client_secret":"...","refresh_token":"..."} vào ô trên → Lưu → bấm 🔑 Kiểm Tra Token để xác minh đúng kênh.
⚠️ Mỗi refresh_token chỉ đại diện một kênh (kênh đang chọn khi cấp quyền). Token dùng chung hoặc đã thu hồi sẽ bị tool chặn để tránh đăng nhầm kênh.
